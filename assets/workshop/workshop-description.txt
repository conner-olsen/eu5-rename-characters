[h1]Overview:[/h1]
Allows you to rename characters and dynasties via the right-click context menu.

[h1]Features:[/h1]
[olist]
 [*][b]Allow Renaming Characters:[/b] You can change the name of any character via the right-click context menu.
 [*][b]Allow Renaming Dynasties:[/b] You can change the name of any dynasty via the right-click context menu on any character.
[/olist]

[h1]To Use:[/h1]
[olist]
 [*][b]Right Click Any Character:[/b] This will open the context menu for character interactions.
 [*][b]Mark Character:[/b] Select the "Mark Character for Renaming" interaction.
 [*][b]Rename Character:[/b] Then select the "Rename Character" interaction.
 [*][b]Choose a New Name:[/b] Fill in the text box with the new name and click "Change Their Name!".
[/olist]
The process for renaming dynasties is the same, just pressing the "Rename Dynasty" instead.

Note: Unfortunately, I could not find a way to make this into a single interaction. This is the best I could do to make it work within the EU5 modding system.

[h1]Important Note on Renaming Dynasties:[/h1]
It is not technically possible to rename any existing dynasty. What is actually happening is the founding of a new dynasty that can be renamed, then moving all the characters into it. However, this will not include deceased characters, and it will change your dynasty's emblem.

Once your dynasty is renamed (/replaced with the renamable one), then these actually can be renamed without issue (no more emblem changes or loss of deceased characters).

Also, there is a limit of 10 renamed dynasties. I can add more if requested; it's just a matter of putting them in one at a time. Currently, only the first dynasty has an emblem I picked out, and the rest use the same generic emblem. I'll accept any suggestions for better emblems on the other 9 dynasties (either send the definition or make a pr with the new emblem).
