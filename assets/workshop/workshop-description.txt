[h1]Overview:[/h1]
Allows you to rename characters via the right-click context menu.

[h1]Features:[/h1]
[olist]
 [*][b]Allow Renaming Characters:[/b] You can change the name of any character via the right-click context menu.
[/olist]

[h1]To Use:[/h1]
[olist]
 [*][b]Right Click Any Character:[/b] This will open the context menu for character interactions.
 [*][b]Mark Character:[/b] Select the "Mark Character for Renaming" interaction.
 [*][b]Rename Character:[/b] Then select the "Rename Character" interaction.
 [*][b]Choose a New Name:[/b] Fill in the text box with the new name and click "Change Their Name!".
[/olist]
Note: Unfortunately, I could not find a way to make this into a single interaction. This is the best I could do to make it work within the EU5 modding system.

[h1]Note on Renaming Dynasties:[/h1]
I've looked in to doing so, but I don't believe it's possible. There isn't any effect available, nor any vanilla case of a dynasty changing name. The only possible workaround I could find is founding a new dynasty that has a dynamic name, then moving all the characters over. It should work, but the coat of arms would be changed as well
