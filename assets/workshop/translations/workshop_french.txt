[h1]Aperçu :[/h1]
Permet de renommer les personnages et les dynasties via le menu contextuel du clic droit.

[h1]Fonctionnalités :[/h1]
[olist]
 [*][b]Permettre de renommer les personnages :[/b] Vous pouvez changer le nom de n'importe quel personnage via le menu contextuel du clic droit.
 [*][b]Permettre de renommer les dynasties :[/b] Vous pouvez changer le nom de n'importe quelle dynastie via le menu contextuel du clic droit sur n'importe quel personnage.
[/olist]

[h1]Utilisation :[/h1]
[olist]
 [*][b]Faites un clic droit sur n'importe quel personnage :[/b] Cela ouvrira le menu contextuel pour les interactions de personnage.
 [*][b]Marquer le personnage :[/b] Sélectionnez l'interaction "Mark Character for Renaming".
 [*][b]Renommer le personnage :[/b] Sélectionnez ensuite l'interaction "Rename Character".
 [*][b]Choisir un nouveau nom :[/b] Remplissez la zone de texte avec le nouveau nom et cliquez sur "Change Their Name!".
[/olist]
Le processus pour renommer les dynasties est le même, il suffit d'appuyer sur "Rename Dynasty" à la place.

Note : Malheureusement, je n'ai pas trouvé de moyen d'en faire une seule interaction. C'est le mieux que j'ai pu faire pour que cela fonctionne dans le système de modding d'EU5.

[h1]Note importante sur le renommage des dynasties :[/h1]
Il n'est techniquement pas possible de renommer une dynastie existante. Ce qui se passe réellement, c'est la fondation d'une nouvelle dynastie qui peut être renommée, puis le transfert de tous les personnages vers celle-ci. Cependant, cela n'inclura pas les personnages décédés, et cela changera l'emblème de votre dynastie.

Une fois que votre dynastie est renommée (ou remplacée par celle renommable), celle-ci peut alors être renommée sans problème (plus de changement d'emblème ou de perte de personnages décédés).

De plus, il y a une limite de 10 dynasties renommées. Je peux en ajouter d'autres sur demande ; c'est juste une question de les intégrer une par une. Actuellement, seule la première dynastie a un emblème que j'ai choisi, et les autres utilisent le même emblème générique. J'accepterai toutes les suggestions pour de meilleurs emblèmes sur les 9 autres dynasties (soit en envoyant la définition, soit en faisant une PR avec le nouvel emblème).
