[h1]Vue d'ensemble :[/h1]
Permet de renommer les personnages et les dynasties via le menu contextuel du clic droit.

[h1]Caractéristiques :[/h1]
[olist]
 [*][b]Autoriser le renommage des personnages :[/b] Vous pouvez changer le nom de n'importe quel personnage via le menu contextuel du clic droit.
 [*][b]Autoriser le renommage des dynasties :[/b] Vous pouvez changer le nom de n'importe quelle dynastie via le menu contextuel du clic droit sur n'importe quel personnage.
[/olist]

[h1]Utilisation :[/h1]
[olist]
 [*][b]Clic droit sur n'importe quel personnage :[/b] Cela ouvrira le menu contextuel pour les interactions de personnage.
 [*][b]Marquer le personnage :[/b] Sélectionnez l'interaction "Marquer le personnage pour renommage".
 [*][b]Sélectionner Renommer Personnage/Dynastie :[/b] Sélectionnez l'interaction "Renommer le personnage" ou "Renommer la dynastie".
 [*][b]Choisir un nouveau nom :[/b] Remplissez la zone de texte avec le nouveau nom et cliquez sur "Changer leur nom !".
[/olist]
Note : Malheureusement, je n'ai pas trouvé le moyen d'en faire une interaction unique. C'est le mieux que j'ai pu faire pour que cela fonctionne avec le système de modding d'EU5.

[h1]Note sur les numéros de règne :[/h1]
Actuellement, même via l'interaction de nommage d'enfant de base (vanilla), les numéros de règne ne sont pas correctement appliqués lorsque votre héritier a le même nom que votre souverain. [url=https://forum.paradoxplaza.com/forum/threads/regnal-numbers.1894770]Paradox a déjà confirmé le rapport de bug à ce sujet ici.[/url]

Ils *fonctionneront* correctement avec mon mod, mais seulement avec les personnages qui ont été renommés en l'utilisant, à l'exclusion de votre souverain actuel.

Par exemple, si vous renommez votre héritier en "John", puis que vous renommez votre héritier suivant en "John" également, le numéro de règne deviendra correctement II une fois que l'héritier suivant montera sur le trône.

[i]Si vous voulez que le numéro de règne correct apparaisse immédiatement, vous pouvez utiliser le mode debug pour déterminer la clé de nom réelle de votre souverain actuel et renommer votre héritier avec celle-ci, ce qui fonctionnera également correctement (les clés de nom sont différentes du nom affiché, par exemple "Baldwin" est "name_baldwin").[/i]

[h1]Note importante sur le renommage des dynasties :[/h1]
Il n'est techniquement pas possible de renommer une dynastie existante. Ce qui se passe réellement est la fondation d'une nouvelle dynastie qui peut être renommée, puis le déplacement de tous les personnages vers celle-ci. Cependant, cela n'inclura pas les personnages décédés et cela changera l'emblème de votre dynastie.

Une fois que votre dynastie est renommée (/remplacée par celle renommable), celle-ci peut alors être renommée sans problème (plus de changements d'emblème ou de perte de personnages décédés).

De plus, il y a une limite de 10 dynasties renommées. Je peux en ajouter plus si demandé ; c'est juste une question de les intégrer une par une. Actuellement, seule la première dynastie a un emblème que j'ai choisi, et les autres utilisent le même emblème générique. J'accepte toute suggestion pour de meilleurs emblèmes pour les 9 autres dynasties (soit en envoyant la définition, soit en faisant une pull request avec le nouvel emblème).

[list]
 [*]Compatible avec les succès (Achievements).
