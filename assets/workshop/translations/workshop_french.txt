[h1]Aperçu :[/h1]
Permet de renommer les personnages et les dynasties via le menu contextuel du clic droit.

[h1]Caractéristiques :[/h1]
[olist]
 [*][b]Autoriser le renommage des personnages :[/b] Vous pouvez changer le nom de n'importe quel personnage via le menu contextuel du clic droit.
 [*][b]Autoriser le renommage des dynasties :[/b] Vous pouvez changer le nom de n'importe quelle dynastie via le menu contextuel du clic droit sur n'importe quel personnage.
[/olist]

[h1]Utilisation :[/h1]
[olist]
 [*][b]Clic droit sur n'importe quel personnage :[/b] Cela ouvrira le menu contextuel des interactions de personnage.
 [*][b]Marquer le personnage :[/b] Sélectionnez l'interaction « Mark Character for Renaming ».
 [*][b]Sélectionner Renommer le personnage/la dynastie :[/b] Sélectionnez l'interaction « Rename Character » ou « Rename Dynasty ».
 [*][b]Choisir un nouveau nom :[/b] Remplissez la zone de texte avec le nouveau nom et cliquez sur « Change Their Name! ».
[/olist]
Note : Malheureusement, je n'ai pas trouvé de moyen d'en faire une interaction unique. C'est le mieux que j'ai pu faire pour que cela fonctionne avec le système de modding d'EU5.

[h1]Note sur les numéros de règne :[/h1]
Actuellement, même via l'interaction de nommage d'enfant de base (vanilla), les numéros de règne ne sont pas correctement appliqués lorsque votre héritier porte le même nom que votre souverain. [url=https://forum.paradoxplaza.com/forum/threads/regnal-numbers.1894770]Paradox a déjà confirmé le rapport de bug à ce sujet ici.[/url]

Ils *fonctionneront* correctement avec mon mod, mais uniquement avec les personnages qui ont été renommés en l'utilisant, à l'exception de votre souverain actuel.

Par exemple, si vous renommez votre héritier en « John », puis que vous renommez également votre héritier suivant en « John », le numéro de règne deviendra correctement II une fois que l'héritier suivant montera sur le trône.

[i]Si vous souhaitez que le numéro de règne correct apparaisse immédiatement, vous pouvez utiliser le mode debug pour déterminer la clé de nom (name key) réelle de votre souverain actuel, puis renommer votre héritier avec celle-ci, ce qui fonctionnera également correctement (les clés de noms sont différentes du nom affiché, par exemple « Baldwin » est « name_baldwin »).[/i]

[h1]Note importante sur le renommage des dynasties :[/h1]
Il n'est techniquement pas possible de renommer une dynastie existante. Ce qui se passe réellement, c'est la fondation d'une nouvelle dynastie qui peut être renommée, puis le transfert de tous les personnages vers celle-ci. Cependant, cela n'inclura pas les personnages décédés et modifiera l'emblème de votre dynastie.

Une fois que votre dynastie est renommée (ou remplacée par celle renommable), celle-ci peut alors être renommée sans problème (plus de changement d'emblème ni de perte de personnages décédés).

De plus, il y a une limite de 10 dynasties renommées. Je peux en ajouter d'autres sur demande ; il s'agit simplement de les ajouter une par une. Actuellement, seule la première dynastie possède un emblème que j'ai choisi, les autres utilisant le même emblème générique. J'accepterai toute suggestion de meilleurs emblèmes pour les 9 autres dynasties (soit en envoyant la définition, soit en faisant une PR avec le nouvel emblème).
