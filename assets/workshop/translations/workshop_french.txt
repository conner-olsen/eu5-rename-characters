Renommer les personnages / Rename Characters
===WORKSHOP_DESCRIPTION===

[h1]Présentation :[/h1]
Vous permet de renommer les personnages via le menu contextuel du clic droit.

[h1]Caractéristiques :[/h1]
[olist]
 [*][b]Autoriser le renommage des personnages :[/b] Vous pouvez changer le nom de n'importe quel personnage via le menu contextuel du clic droit.
[/olist]

[h1]Utilisation :[/h1]
[olist]
 [*][b]Clic droit sur n'importe quel personnage :[/b] Cela ouvrira le menu contextuel des interactions de personnage.
 [*][b]Marquer le personnage :[/b] Sélectionnez l'interaction "Marquer le personnage pour renommage".
 [*][b]Renommer le personnage :[/b] Sélectionnez ensuite l'interaction "Renommer le personnage".
 [*][b]Choisir un nouveau nom :[/b] Remplissez la zone de texte avec le nouveau nom et cliquez sur "Changer leur nom !".
[/olist]
Note : Malheureusement, je n'ai pas trouvé de moyen d'en faire une interaction unique. C'est le mieux que j'ai pu faire pour que cela fonctionne avec le système de modding d'EU5.
