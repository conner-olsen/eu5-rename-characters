[h1]Vue d'ensemble :[/h1]
Permet de renommer les personnages et les dynasties via le menu contextuel du clic droit.

[h1]Fonctionnalités :[/h1]
[olist]
 [*][b]Autoriser le renommage des personnages :[/b] Vous pouvez changer le nom de n'importe quel personnage via le menu contextuel du clic droit.
 [*][b]Autoriser le renommage des dynasties :[/b] Vous pouvez changer le nom de n'importe quelle dynastie via le menu contextuel du clic droit sur n'importe quel personnage.
[/olist]

[h1]Utilisation :[/h1]
[olist]
 [*][b]Clic droit sur n'importe quel personnage :[/b] Cela ouvrira le menu contextuel des interactions avec les personnages.
 [*][b]Marquer le personnage :[/b] Sélectionnez l'interaction "Mark Character for Renaming" (Marquer le personnage pour renommage).
 [*][b]Sélectionner Renommer le personnage/la dynastie :[/b] Sélectionnez l'interaction "Rename Character" ou "Rename Dynasty".
 [*][b]Choisir un nouveau nom :[/b] Remplissez la zone de texte avec le nouveau nom et cliquez sur "Change Their Name !".
[/olist]
Note : Malheureusement, je n'ai pas trouvé de moyen d'en faire une seule interaction. C'est le mieux que j'ai pu faire pour que cela fonctionne dans le système de modding d'EU5.

[h1]Note sur les chiffres régnal :[/h1]
Actuellement, même via l'interaction de base pour nommer les enfants, les chiffres régnal ne sont pas appliqués correctement, même lorsque votre héritier porte le même nom que votre souverain.

Veuillez voter pour ce [url=https://forum.paradoxplaza.com/forum/threads/regnal-numbers-not-working.1867905/]rapport de bug sur le forum pour aider à le corriger.[/url]

Ils *fonctionneront* correctement avec mon mod, mais uniquement avec les personnages qui ont été renommés en l'utilisant, sans inclure votre souverain actuel.

Par exemple, si vous renommez votre héritier en "John", puis que vous renommez également votre héritier suivant en "John", le chiffre régnal deviendra correctement II une fois que l'héritier suivant montera sur le trône.

[i]Techniquement, si vous le souhaitez, vous pouvez utiliser le mode debug pour déterminer la clé de nom réelle de votre souverain actuel, puis renommer votre héritier avec celle-ci, ce qui fonctionnera également correctement (les clés de nom sont différentes du nom affiché, par exemple "Baldwin" est "name_baldwin").[/i]

[h1]Note importante sur le renommage des dynasties :[/h1]
Il n'est techniquement pas possible de renommer une dynastie existante. Ce qui se passe réellement, c'est la fondation d'une nouvelle dynastie qui peut être renommée, puis le déplacement de tous les personnages vers celle-ci. Cependant, cela n'inclura pas les personnages décédés, et cela changera l'emblème de votre dynastie.

Une fois que votre dynastie est renommée (ou remplacée par celle renommable), elle peut alors être renommée sans problème (plus de changements d'emblème ou de perte de personnages décédés).

De plus, il y a une limite de 10 dynasties renommées. Je peux en ajouter plus si demandé ; il suffit de les intégrer une par une. Actuellement, seule la première dynastie possède un emblème que j'ai choisi, et les autres utilisent le même emblème générique. J'accepterai toute suggestion de meilleurs emblèmes pour les 9 autres dynasties (soit en envoyant la définition, soit en faisant une pr avec le nouvel emblème).
