Charaktere umbenennen / Rename Characters & Dynasties
===WORKSHOP_DESCRIPTION===

[h1]Überblick:[/h1]
Ermöglicht es Ihnen, Charaktere und Dynastien über das Rechtsklick-Kontextmenü umzubenennen.

[h1]Funktionen:[/h1]
[olist]
 [*][b]Umbenennen von Charakteren:[/b] Sie können den Namen eines jeden Charakters über das Rechtsklick-Kontextmenü ändern.
 [*][b]Umbenennen von Dynastien:[/b] Sie können den Namen jeder Dynastie über das Rechtsklick-Kontextmenü eines beliebigen Charakters ändern.
[/olist]

[h1]Verwendung:[/h1]
[olist]
 [*][b]Rechtsklick auf einen beliebigen Charakter:[/b] Dies öffnet das Kontextmenü für Charakterinteraktionen.
 [*][b]Charakter markieren:[/b] Wählen Sie die Interaktion „Charakter zum Umbenennen markieren“ (Mark Character for Renaming).
 [*][b]Charakter umbenennen:[/b] Wählen Sie dann die Interaktion „Charakter umbenennen“ (Rename Character).
 [*][b]Einen neuen Namen wählen:[/b] Geben Sie den neuen Namen in das Textfeld ein und klicken Sie auf „Namen ändern!“ (Change Their Name!).
[/olist]
Der Vorgang zum Umbenennen von Dynastien ist derselbe, drücken Sie stattdessen einfach auf „Dynastie umbenennen“ (Rename Dynasty).

Hinweis: Leider konnte ich keinen Weg finden, dies in einer einzigen Interaktion zusammenzufassen. Dies ist die beste Lösung, um es innerhalb des EU5-Modding-Systems zum Laufen zu bringen.

[h1]Wichtiger Hinweis zum Umbenennen von Dynastien:[/h1]
Technisch gesehen ist es nicht möglich, eine bestehende Dynastie umzubenennen. Tatsächlich wird eine neue Dynastie gegründet, die umbenannt werden kann, und anschließend werden alle Charaktere in diese verschoben. Verstorbene Charaktere werden jedoch nicht übernommen, und das Wappen Ihrer Dynastie wird sich ändern.

Sobald Ihre Dynastie umbenannt (bzw. durch die umbenennbare ersetzt) wurde, kann diese ohne Probleme erneut umbenannt werden (keine weiteren Wappenänderungen oder Verlust von verstorbenen Charakteren).

Außerdem gibt es ein Limit von 10 umbenannten Dynastien. Ich kann auf Anfrage weitere hinzufügen; es geht lediglich darum, sie einzeln einzufügen. Derzeit hat nur die erste Dynastie ein von mir ausgewähltes Wappen, der Rest verwendet dasselbe generische Wappen. Ich nehme gerne Vorschläge für bessere Wappen für die anderen 9 Dynastien entgegen (senden Sie entweder die Definition oder erstellen Sie einen Pull Request mit dem neuen Wappen).
